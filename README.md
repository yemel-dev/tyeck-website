# TYECK — Site Web Vitrine

Site vitrine officiel de **TYECK**, agence de développement digital basée à Kinshasa (RDC), spécialisée dans la création de sites web, applications web, plateformes e-commerce et solutions digitales sur mesure.

> « Votre présence digitale, notre mission »

## 🚀 Stack technique

- **React** (via Vite)
- **TypeScript**
- **Tailwind CSS**
- Déploiement : Vercel / Netlify

## 📁 Structure du projet

src/
components/
layout/ → Navbar, Footer
sections/ → Hero, Services, Portfolio, Testimonials, Contact
ui/ → Composants réutilisables (Button, Card...)
data/ → Contenu textuel du site (content.ts)
types/ → Interfaces TypeScript partagées
assets/ → Logos, images

## 🛠️ Installation

Cloner le dépôt puis installer les dépendances :

```bash
git clone https://github.com/TON_USERNAME/tyeck-website.git
cd tyeck-website
npm install
```

## 💻 Lancer en local

```bash
npm run dev
```

Le site sera accessible sur `http://localhost:5173`

## 📦 Build de production

```bash
npm run build
```
